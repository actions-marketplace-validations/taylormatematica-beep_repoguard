Rules Engine

12 Strict Architectural Guardrails

Zero config needed. Multi-language architectural defense across TypeScript, Python, and Golang.

RULE-01 Error

No Direct DB in UI

Blocks raw ORM/Prisma/SQL queries inside React components and API controllers. Enforces dedicated service layers.

RULE-PY-01 Python

FastAPI Layer Separation

Prohibits direct ORM queries and raw database commits (db.commit()) inside FastAPI route handlers.

RULE-GO-01 Golang

Go Clean Architecture

Prohibits raw database/GORM mutations inside Gin, Fiber, or Echo HTTP handlers. Enforces repository pattern.

RULE-GO-02 Golang

No Silenced Go Errors

Catches errors discarded with blank identifiers (_ = err), preventing AI from suppressing compiler strictness.

RULE-02 Critical

Secret Leak Blocker

Catches hardcoded API keys, tokens, and credentials before they get committed to GitHub.

RULE-09 Critical

Client-Side Secret Exposure

Detects sensitive credentials accidentally prefixed with NEXT_PUBLIC_ or VITE_ bundled into browser JS.

RULE-03 Warning

No Lazy ": any"

Prevents AI models from escaping type safety by throwing : any or as any to pass compilation.

RULE-04 Info

Logger Hygiene

Flags stray console.log calls and enforces centralized, structured production loggers.

RULE-05 Error

SSR Hydration Guard

Prevents Next.js Server Components from calling window or localStorage directly.

RULE-06 Critical

SQL Injection Hazard

Detects dangerous unescaped string interpolations in raw SQL queries and requires parameterized input.

RULE-07 Warning

Unvalidated Payloads

Requires incoming API route payloads to be parsed through Zod schemas before being used.

RULE-08 Info

Anti-Duplicate Utils

Stops AI assistants from re-inventing standard helpers (date formatters, validators) that already exist in /utils.
